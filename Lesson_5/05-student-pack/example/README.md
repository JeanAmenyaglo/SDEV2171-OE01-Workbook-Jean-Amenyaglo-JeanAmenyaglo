# Lesson 05 Example Materials

This folder contains the instructor reference project for lesson 05.

## Teaching purpose
- show how the lesson-04 structure becomes easier to read with deliberate styles
- demonstrate `StyleSheet.create`, spacing, alignment, and text hierarchy
- provide a known-good styled screen that can be used for lesson 06 navigation work

## Course baseline
Verified against official React Native documentation on `2026-06-04T05:38Z`.

- Expo SDK 56
- React Native 0.85
- React 19.2.3
- Node.js 22.13.x or newer

## Teaching decision
This reference app improves readability and structure without turning the lesson into branding or design-system work. It should feel cleaner than lesson 04, but still simple enough that students can explain why each style change matters.

## Reference project
Use `styling-reference/` for:
- the instructor demo
- the guided build target
- a recovery path for students whose lesson-04 app is not yet ready
