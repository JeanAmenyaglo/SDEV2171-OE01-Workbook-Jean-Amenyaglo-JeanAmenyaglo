# Lesson 03 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `project-creation-checklist.md` during class.
2. Use `project-structure-reference.md` when you need to understand the generated files.
3. Use `troubleshooting-checklist.md` if the app does not create, start, or launch correctly.
4. Use the reference project in `example/` only if the instructor directs you to it.
5. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The exercise is a reflection and reinforcement task after the guided build.
