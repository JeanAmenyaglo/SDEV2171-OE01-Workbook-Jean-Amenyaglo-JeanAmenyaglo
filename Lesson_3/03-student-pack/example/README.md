# Lesson 03 Example Materials

This folder contains the instructor reference project for lesson 03.

## Teaching purpose
- demonstrate the exact file structure students are expected to understand in lesson 03
- show a minimal `App.js` that students can modify safely
- provide a known reference point for lesson 04 component work

## Course baseline
Verified against official Expo documentation on `2026-06-04T04:16Z`.

- Expo SDK 56
- React Native 0.85
- React 19.2.3
- Node.js 22.13.x or newer

## Course decision
Expo’s published default template is multi-screen and router-enabled. This lesson intentionally uses the `blank` template so students can focus on:
- creating a project successfully
- understanding the main files
- observing direct changes in `App.js`

## Reference project
Use `first-expo-app-reference/` for:
- a demo run
- a file-structure walkthrough
- a safe source for projector-side code edits

This reference app is a prepared demo variant. Students creating a brand-new blank project in class should not expect their first generated screen to match it exactly.
