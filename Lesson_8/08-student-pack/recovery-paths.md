# Lesson 08 Recovery Paths

Use this guide if one foundation area is still partial or blocked.

## If styling is the weak point
Return to lesson 05:
- [lesson-05/guided-build-checklist.md](../lesson-05/guided-build-checklist.md)
- [lesson-05/styling-reference.md](../lesson-05/styling-reference.md)
- [lesson-05/troubleshooting-checklist.md](../lesson-05/troubleshooting-checklist.md)

Repair target:
- make one screen readable
- improve spacing, text hierarchy, and one consistency issue

Return to lesson 08 when:
- the screen is readable again
- you can name the styling improvement you fixed
- then return to Step 4 of `work-session-checklist.md`

## If navigation is the weak point
Return to lesson 06:
- [lesson-06/navigation-build-checklist.md](../lesson-06/navigation-build-checklist.md)
- [lesson-06/screen-flow-reference.md](../lesson-06/screen-flow-reference.md)
- [lesson-06/navigation-status-tracker.md](../lesson-06/navigation-status-tracker.md)
- [lesson-06/troubleshooting-checklist.md](../lesson-06/troubleshooting-checklist.md)

Repair target:
- restore one working forward path
- restore one working return path
- confirm `configured` navigation before moving on

Return to lesson 08 when:
- one forward path works
- one return path works
- then return to Step 4 of `work-session-checklist.md`

## If input is the weak point
Return to lesson 07:
- [lesson-07/interaction-build-checklist.md](../lesson-07/interaction-build-checklist.md)
- [lesson-07/input-pattern-reference.md](../lesson-07/input-pattern-reference.md)
- [lesson-07/starter-snippets.md](../lesson-07/starter-snippets.md)
- [lesson-07/troubleshooting-checklist.md](../lesson-07/troubleshooting-checklist.md)

Repair target:
- restore one input field
- restore one press action
- restore one visible response after the action

Return to lesson 08 when:
- the input field works
- the press action works
- the visible response changes
- then return to Step 4 of `work-session-checklist.md`

## If more than one area is weak
Repair in this order:
1. navigation
2. input
3. styling

Reason:
- navigation is the base structure
- input depends on a stable screen
- styling can be improved once the flow works
