# Lesson 08 Success Criteria

Use this page before the checkpoint.

## A stable lesson-08 project should show all three

### Styling
- the screen or screens look intentionally spaced
- text is readable
- repeated areas feel visually consistent

### Navigation
- the user can move forward between screens
- the user can return without breaking the app
- the route flow is easy to explain

### Input
- the user can type into one field
- the user can trigger one action
- the screen shows a visible result after the interaction

## Stronger work also shows
- one clear explanation of what was fixed
- one clear explanation of what still needs repair, if anything
- one integrated flow rather than three disconnected features

## Readiness language
- `quiz-ready` means all three areas above are working together
- `still repairing` means one area is still incomplete, even if the blocker is documented clearly
