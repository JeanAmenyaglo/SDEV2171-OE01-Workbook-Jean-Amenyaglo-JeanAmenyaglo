# Lesson 08 Progress Tracker

Use this tracker during the work period or before the end-of-class checkpoint.

## Current path
- `build`
- `repair`

## Status meaning
- `build`: trying to finish all required tasks
- `repair`: trying to restore one blocked or partial area first

## Required task status
- Styling cleanup:
  - `complete`
  - `partial`
  - `blocked`
- Navigation flow:
  - `complete`
  - `partial`
  - `blocked`
- Input-driven interaction:
  - `complete`
  - `partial`
  - `blocked`

## Optional challenge status
- `not started`
- `in progress`
- `complete`

## Current main blocker
Write one short sentence:
- which area is weakest right now
- what is failing

## Next action
Write one short sentence:
- what you will fix next
- which file or lesson reference you will use

## Checkpoint evidence
Be ready to show:
- one styling improvement
- one working forward navigation path plus one working return path
- one working input-response flow
