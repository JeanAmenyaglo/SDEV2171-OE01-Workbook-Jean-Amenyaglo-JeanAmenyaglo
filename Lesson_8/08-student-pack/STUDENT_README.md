# Lesson 08 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `work-session-checklist.md`.
2. Open `worked-example.md` to review one modeled target and default file anchors.
3. Use `exercise.md` to complete the required tasks.
4. Open `success-criteria.md` to verify whether the work is actually complete.
5. Use `recovery-paths.md` if one foundation area is still partial or blocked.
6. Record status in `progress-tracker.md` before the checkpoint.

## Important Note
Students should begin with the work-session documents in this folder, not by reopening older lesson exercises. Older lesson files are referenced only through `recovery-paths.md` when targeted repair is needed.
