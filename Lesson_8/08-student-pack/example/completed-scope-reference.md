# Completed Scope Reference

Use this note during the lesson-08 work period when you need a quick judgment about whether a student solution is stable enough.

## Minimum stable checkpoint solution

### Styling
- one readable screen
- visible spacing between sections
- readable text hierarchy
- at least one consistency improvement across repeated elements

### Navigation
- one working forward navigation action
- one working return path
- a route structure the student can explain

### Input
- one text input field
- one action trigger such as a button press
- one visible response after the interaction

## Not yet stable
Do not treat a project as stable if:
- navigation still breaks
- the input action produces no visible result
- the student cannot explain which area is still failing

## Optional challenge threshold
Only push a student into the optional challenge if the required styling, navigation, and input tasks are already stable.
