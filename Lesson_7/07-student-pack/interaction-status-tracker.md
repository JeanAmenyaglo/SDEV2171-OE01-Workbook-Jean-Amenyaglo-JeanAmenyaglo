# Lesson 07 Interaction Status Tracker

Use this tracker during or at the end of class.

## Status options
- `configured`
  Input works, the press action works, and the visible response is clear.
- `partial`
  The interaction flow exists, but one part still fails.
- `blocked`
  The interaction flow cannot be completed during class progress.

## Record these items
- current status
- which project you worked in:
  - your own project
  - the instructor-guided reference path
- current failing step, if any
- one next action to try before lesson 08

## Example status notes
- `configured`: the user can type, press the action, and see the response area update.
- `partial`: the input field appears, but the response still does not change after the press.
- `blocked`: the lesson-06 baseline was not ready, so the instructor-guided reference path was used and the next step is to complete the lesson-06 remediation first.

## Lesson-08 readiness rule
- `configured` is lesson-08-ready.
- `partial` and `blocked` are not lesson-08-ready yet.
- If your status is `partial` or `blocked`, complete the lesson-06 remediation if needed, then verify:
  1. navigation still works
  2. the input field accepts text
  3. the press action runs
  4. the visible response changes
  5. your status is updated to `configured`
