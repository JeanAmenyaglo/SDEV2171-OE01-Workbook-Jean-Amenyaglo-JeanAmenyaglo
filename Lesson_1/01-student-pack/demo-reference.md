# Lesson 01 Demo Reference

This guide is the student-facing reference for the in-class Expo demo app. Use it when completing the lesson-01 exercise. You do not need to install or run the app for this lesson.

## Quick Vocabulary
- **screen**: one major view in the app, such as Home or Planner
- **component**: a reusable UI piece, such as a button, text label, card, or text input
- **navigation**: the way a user moves between screens
- **feedback preview**: a visible interface change after a user action; we will study this more later

## Screen Map
### Home
- Main purpose: introduce the demo app and show three course focus cards
- Notable components:
  - heading text
  - summary text
  - feature cards
  - call-to-action button

### Explore
- Main purpose: compare native, hybrid, and cross-platform approaches
- Notable components:
  - section title
  - comparison cards
  - callout box about React Native and Expo

### Planner
- Main purpose: show simple interaction and feedback
- Notable components:
  - section title
  - selectable topic badges
  - multiline text input
  - summary card

## Navigation Pattern
The app uses a bottom navigation bar with three choices:
- Home
- Explore
- Planner

This lets the user switch directly between the main screens.

## Example Component List
If you need help naming components, these are all valid examples from the app:
- text heading
- paragraph text
- card
- button
- badge or chip
- text input
- navigation button
- summary panel

## Example User Feedback
The Planner screen gives immediate feedback:
- when a topic badge is tapped, its appearance changes
- when the note is edited, the summary card updates

For lesson 01, treat this as a preview of later interaction concepts rather than a required deep topic.

## Reminder For Part 1
If you are unsure whether an outside app is native, hybrid, or cross-platform, it is acceptable to say you are uncertain and explain the clues you noticed.
