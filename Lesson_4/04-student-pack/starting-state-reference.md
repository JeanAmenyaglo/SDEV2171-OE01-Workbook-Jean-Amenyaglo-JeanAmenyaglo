# Lesson 04 Starting State Reference

Use this reference if you are unsure what “start from the lesson-03 project” means.

## Expected shared baseline
Before lesson 04, the student project should already have:
- a working Expo app from lesson 03
- `SafeAreaView`
- `View`
- `Text`
- a known-good `App.js` that still runs

## Mental model
Lesson 03 proved:
- the project opens
- the app runs
- one saved edit changes the screen

Lesson 04 adds:
- `ScrollView`
- `Image`
- `TextInput`
- more deliberate `View` and `Text` structure

## Minimal baseline example
This is not a full copy target. It is only a reminder of the kind of screen state students are starting from:

```js
<SafeAreaView>
  <View>
    <Text>Lesson 03 heading</Text>
    <Text>Lesson 03 body text</Text>
  </View>
</SafeAreaView>
```

## If your project is not in this state
- recover one working path first, or
- use the instructor recovery app during class and record the changes you made yourself
