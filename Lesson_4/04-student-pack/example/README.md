# Lesson 04 Example Materials

This folder contains the instructor reference project for lesson 04.

## Teaching purpose
- extend the lesson-03 starter app into a simple structured screen
- demonstrate `View`, `Text`, `Image`, `ScrollView`, and `TextInput`
- provide a known-good screen that lesson 05 can style next

## Course baseline
Verified against official Expo and React Native documentation on `2026-06-04T04:32Z`.

- Expo SDK 56
- React Native 0.85
- React 19.2.3
- Node.js 22.13.x or newer

## Teaching decision
This reference app is intentionally small. It is more complete than the raw lesson-03 starter, but still limited enough that students can understand the structure and modify it in one class.

Carryover items from earlier lessons:
- `SafeAreaView`
- `StatusBar`
- `StyleSheet`

These are not the main teaching target in lesson 04. The in-class focus is the added `View`, `Text`, `Image`, `ScrollView`, and `TextInput` structure.

## Reference project
Use `core-components-reference/` for:
- the instructor demo
- the guided build target
- a recovery path for students whose lesson-03 app is not yet ready

Students using this recovery path can still complete the exercise if they clearly identify which changes or observations were their own work during class.
