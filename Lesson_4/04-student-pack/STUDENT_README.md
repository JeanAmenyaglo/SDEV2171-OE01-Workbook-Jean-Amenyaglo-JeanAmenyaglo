# Lesson 04 Student README

This file contains the student-facing usage order for this lesson bundle.

1. Start with `guided-build-checklist.md` during class.
2. Check `starting-state-reference.md` before building if you are unsure about your baseline.
3. Use `starter-snippets.md` and `component-reference.md` while building.
4. Use `troubleshooting-checklist.md` if the app breaks or the screen does not match expectations.
5. Use the reference app in `example/` only if the instructor directs you to it.
6. Complete `exercise.md` after class.

## Important Note
Students should not begin with `exercise.md`. The guided build and support references come first.
