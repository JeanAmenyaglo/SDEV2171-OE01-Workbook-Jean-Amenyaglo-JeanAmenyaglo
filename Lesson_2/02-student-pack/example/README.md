# Lesson 02 Instructor Example

This folder contains the instructor-facing verification app and notes for lesson 02.

## Purpose
The example exists to verify that student environments can start and open an Expo app before lesson 03 asks students to create their own project.

## Contents
- `environment-check-app/`: lightweight Expo verification app aligned to the course baseline

## Instructor Walkthrough Plan
1. Open the verification app folder in a terminal.
2. Start the Expo server and narrate the meaning of each visible step.
3. Launch the app on one working path first.
4. If possible, demonstrate the second path briefly.
5. Use the app screen to define what counts as `verified`.
6. Transition students into the shared setup checklist.

## What To Emphasize
- Verification comes before customization.
- One working path is enough for lesson 02.
- Students should track evidence and next steps if setup is incomplete.
- The exact repo path for the sample app is `resources/01-foundations-setup/lesson-02/example/environment-check-app`.

## Guardrails
- Do not let the demo turn into a long environment lecture before students start working.
- Keep troubleshooting step-based and visible.
- If a student cannot finish setup, make sure they still leave with a status and next action.
